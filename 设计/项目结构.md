# 🧠 多角色智能问答系统 — 项目结构

> RAG-based Multi-Role Dialogue System

---

## 📋 项目概览

- 基于RAG的多角色智能对话平台
- 支持3个专业角色：律师 / 心理咨询师 / 医学专家
- 知识库检索增强生成 (RAG)
- SSE流式对话 + 多格式文件解析

---

## 🛠️ 技术栈

### 后端框架
- **FastAPI + Uvicorn** — Web服务
- **Nginx** — 反向代理

### 数据库
- **MySQL** — 用户/角色/聊天记录持久化
- **Redis** — 对话记忆缓存 (TTL 300s) + SMS验证码
- **Milvus (Docker)** — 向量数据库

### AI / NLP
- **BGE-M3** — 文本嵌入 (1024维)
- **BGE-Reranker** — 精排重排序
- **DeepSeek V4-Flash API** — LLM推理

### 安全
- **JWT** — 认证 (auth.py)
- **bcrypt** — 密码哈希
- **slowapi** — 接口限流

---

## 📂 核心模块 (`src/`)

```
src/
├── fastapi_app.py          # 1304行 · API路由 + RAG管线 + SSE流式
├── config/
│   └── settings.py         # 全局配置
├── db/
│   ├── mysql.py            # 用户/角色/聊天CRUD
│   └── redis.py            # 对话缓存 + SMS验证码
├── rag/
│   ├── chunking.py         # 文本分块 (500字)
│   ├── embedding.py        # BGE-M3 向量嵌入
│   ├── retrieval.py        # Milvus 向量检索
│   ├── rerank.py           # BGE-Reranker 精排
│   ├── load_file.py        # 多格式加载 (PDF/DOCX/PPT/OCR)
│   └── llm_chat.py         # LLM对话 (遗留模块)
└── utils/
    ├── auth.py             # JWT认证
    └── logger.py           # 日志系统
```

## 🔄 RAG管线流程

```
用户提问
  ↓
① 文本分块 (chunking, 500字)
  ↓
② BGE-M3 向量嵌入 (1024d)
  ↓
③ Milvus 向量检索 (Top-K)
  ↓
④ BGE-Reranker 精排重排
  ↓
⑤ Prompt模板 + 检索结果 + 上下文
  ↓
⑥ DeepSeek LLM 生成回答
  ↓
⑦ SSE流式返回客户端
```
