# 文本清理方案

## 1. 问题描述

RAG系统返回的回答包含Markdown格式符号：
- `**粗体**`：星号
- `# 标题`：井号
- `| 表格 |`：管道符
- `--`：分隔符

TTS会把这些符号读出来，影响语音质量。

## 2. 解决方案

### 2.1 清理函数

```python
import re

def clean_text_for_tts(text):
    """清理文本中的Markdown符号，让TTS读得更自然"""
    text = re.sub(r'\*+', '', text)        # 去掉*
    text = re.sub(r'#+\s*', '', text)      # 去掉#
    text = re.sub(r'\|', '，', text)        # 表格|转逗号
    text = re.sub(r'-{2,}', '', text)       # 去掉--
    text = re.sub(r'\n+', '。', text)       # 换行转句号
    text = re.sub(r'。{2,}', '。', text)    # 去掉重复句号
    text = re.sub(r'，{2,}', '，', text)    # 去掉重复逗号
    text = text.strip()
    if not text.endswith(('。', '！', '？', '.', '!', '?')):
        text += '。'
    return text
```

### 2.2 清理规则

| 符号 | 处理方式 | 原因 |
|------|----------|------|
| `*` | 删除 | 不需要读出 |
| `#` | 删除 | 不需要读出 |
| `|` | 替换为逗号 | 表格分隔符转为停顿 |
| `--` | 删除 | 分隔符 |
| `\n` | 替换为句号 | 换行转为停顿 |
| 重复句号 | 合并为一个 | 避免重复 |
| 重复逗号 | 合并为一个 | 避免重复 |

### 2.3 示例

**清理前**：
```
**Premier Farnell**：全球领先的多渠道分销商\n\n**Electrocomponents**：电子元器件分销商
```

**清理后**：
```
Premier Farnell：全球领先的多渠道分销商。Electrocomponents：电子元器件分销商。
```

## 3. 效果对比

| 指标 | 清理前 | 清理后 |
|------|--------|--------|
| 语音质量 | 有杂音（*号等） | 清晰自然 |
| 可读性 | 差 | 好 |
| 用户体验 | 差 | 好 |

## 4. 结论

文本清理是必要的预处理步骤，能显著提升TTS语音质量。
