# 部署指南

## 1. 环境要求

### 1.1 本地环境（RAG系统）

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| Python | 3.10+ |
| Docker | 用于运行Milvus和Redis |
| GPU | 可选（CPU模式可用） |

### 1.2 AutoDL环境（数字人系统）

| 项目 | 要求 |
|------|------|
| GPU | RTX 3090 24GB 或更高 |
| Python | 3.10.8 |
| PyTorch | 2.1.2+cu121 |
| 数据盘 | 100GB+ |

## 2. 部署步骤

### 2.1 本地RAG部署

**步骤1：启动Docker容器**
```powershell
# 启动Milvus
docker start milvus

# 启动Redis
docker start docker-redis-1
```

**步骤2：启动RAG服务**
```powershell
cd E:\桌面\项目文件\RAG工单项目\工单六
$env:EMBEDDING_DEVICE="cpu"
.venv\Scripts\python.exe run.py
```

**步骤3：测试API**
```powershell
Invoke-RestMethod -Uri "http://localhost:8006/api/query" -Method POST -ContentType "application/json" -Body '{"question": "你好", "strategy": "hybrid"}'
```

### 2.2 ngrok内网穿透

**步骤1：启动ngrok**
```powershell
ngrok http 8006
```

**步骤2：获取公网地址**
```
Forwarding    https://xxxx.ngrok-free.dev -> http://localhost:8006
```

**步骤3：测试公网API**
```powershell
Invoke-RestMethod -Uri "https://xxxx.ngrok-free.dev/api/query" -Method POST -ContentType "application/json" -Body '{"question": "你好", "strategy": "hybrid"}'
```

### 2.3 AutoDL数字人部署

**步骤1：克隆实例**

从已有实例克隆，保留环境和模型。

**步骤2：上传代码和图片**

```bash
# 上传主程序
scp rag_digital_human.py root@autodl:/root/autodl-tmp/Linly-Talker/

# 上传图片
scp 金融男.png root@autodl:/root/autodl-tmp/Linly-Talker/inputs/
```

**步骤3：修改配置**

编辑`rag_digital_human.py`，修改：
- `RAG_API_URL`：ngrok公网地址
- `SOURCE_IMAGE`：数字人图片路径
- `TTS_VOICE`：语音选择

**步骤4：启动服务**

```bash
cd /root/autodl-tmp/Linly-Talker
source /root/miniconda3/etc/profile.d/conda.sh
conda activate
python rag_digital_human.py
```

**步骤5：访问WebUI**

AutoDL控制台 → 自定义服务 → 6006端口

## 3. 常见问题

### 3.1 CUDA显存不足

**问题**：`CUDA out of memory`

**解决**：
```powershell
$env:EMBEDDING_DEVICE="cpu"
```

### 3.2 ngrok返回警告页面

**问题**：JSON解析失败

**解决**：添加header
```python
headers = {'ngrok-skip-browser-warning': 'true'}
```

### 3.3 TTS读出*号

**问题**：RAG返回的Markdown符号被读出

**解决**：添加clean_text函数清理文本

### 3.4 口型对不上

**问题**：纯MuseTalk只有嘴巴动

**解决**：使用SadTalker+MuseTalk组合方案

## 4. 维护说明

### 4.1 日常维护

1. 确保本地RAG服务运行
2. 确保ngrok连接正常
3. 监控AutoDL实例状态

### 4.2 更新流程

1. 更新本地RAG代码
2. 重启RAG服务
3. 更新AutoDL代码（如需要）
4. 重启数字人服务

### 4.3 故障排查

1. 检查本地RAG是否运行
2. 检查ngrok是否连接
3. 检查AutoDL实例状态
4. 查看日志文件
