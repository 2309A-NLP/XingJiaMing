## 一、项目概述

### 1.1 项目目标

构建一个金融垂直领域的数字人问答系统，用户输入金融问题后，数字人能够：
1. 基于金融知识库（RAG）检索相关信息
2. 由LLM生成专业回答
3. 通过TTS将回答转为语音
4. 驱动数字人生成说话视频

### 1.2 系统架构

```
用户输入问题 → RAG检索（本地8006端口） → LLM生成回答 → TTS语音合成 → 数字人视频生成
```

### 1.3 技术栈

| 模块 | 技术方案 | 说明 |
|------|---------|------|
| RAG系统 | FastAPI + Milvus + BGE-M3 + DeepSeek-Chat | 本地部署，ngrok内网穿透 |
| TTS语音 | Edge-TTS（zh-CN-YunyangNeural） | 微软语音合成，男声 |
| 数字人 | SadTalker + MuseTalk组合方案 | SadTalker生成自然表情，MuseTalk优化口型 |
| 部署平台 | AutoDL算力云（RTX 3090） | 云端GPU计算 |

### 3.3 方案探索与优化

#### 方案1：纯SadTalker

**优点**：脸部动作自然（眨眼、头部微动）
**缺点**：口型同步一般
**耗时**：约99秒

#### 方案2：纯MuseTalk

**优点**：口型同步好
**缺点**：只有嘴巴动，脸部僵硬
**耗时**：约75秒

#### 方案3：SadTalker + MuseTalk组合（最终方案）

**优点**：既有自然的脸部动作，口型又准
**缺点**：耗时较长
**耗时**：约540秒（9分钟）

**实现流程**：
1. SadTalker生成带动脸部表情的基础视频
2. MuseTalk基于基础视频优化口型同步

### 3.4 文本清理

RAG返回的回答包含Markdown符号（如`**粗体**`），TTS会把`*`读出来。

**解决方案**：在TTS前清理文本
```python
def clean_text(text):
    text = re.sub(r'\*+', '', text)        # 去掉*
    text = re.sub(r'#+\s*', '', text)      # 去掉#
    text = re.sub(r'\|', '，', text)        # 表格|转逗号
    text = re.sub(r'-{2,}', '', text)       # 去掉--
    text = re.sub(r'\n+', '。', text)       # 换行转句号
    text = re.sub(r'。{2,}', '。', text)    # 去掉重复句号
    text = re.sub(r'，{2,}', '，', text)    # 去掉重复逗号
    text = text.strip()
    if not text.endswith(('。', '！', '？', '.', '!', '?')):
        text += '。'
    return text
```

### 3.5 ngrok问题处理

ngrok免费版会返回浏览器警告页面，导致JSON解析失败。

**解决方案**：添加header
```python
headers = {'ngrok-skip-browser-warning': 'true'}
```

## 四、核心代码

### 4.1 RAG客户端

```python
import requests

RAG_API_URL = 'https://herself-ferment-accustom.ngrok-free.dev'
HEADERS = {'ngrok-skip-browser-warning': 'true'}

def query_rag(question, strategy='hybrid'):
    try:
        r = requests.post(
            f'{RAG_API_URL}/api/query',
            json={'question': question, 'strategy': strategy},
            headers=HEADERS,
            timeout=30
        )
        return r.json().get('answer', 'RAG未返回有效回答。')
    except Exception as e:
        return f'RAG出错: {str(e)}'
```

### 4.2 TTS语音合成

```python
from TTS import EdgeTTS

edgetts = EdgeTTS()
edgetts.predict(
    text=clean_text,
    voice='zh-CN-YunyangNeural',  # 男声
    rate=0,
    volume=100,
    pitch=0,
    save_path='answer.wav',
    subtitle_path='answer.vtt'
)
```

### 4.3 SadTalker + MuseTalk组合

```python
from TFG import SadTalker, MuseTalk_RealTime

# Step 1: SadTalker生成基础视频
sadtalker = SadTalker(lazy_load=True)
sadtalker_video = sadtalker.test2(
    source_image, audio_path,
    preprocess='crop',
    still_mode=False,
    use_enhancer=False,
    batch_size=2,
    size=256,
    pose_style=0,
    facerender='facevid2vid',
    exp_scale=1.0,
    use_ref_video=False,
    ref_info='pose',
    use_idle_mode=False,
    length_of_audio=0,
    use_blink=True,
    fps=20
)

# Step 2: MuseTalk优化口型
musetalker = MuseTalk_RealTime()
musetalker.init_model()
musetalker.prepare_material(sadtalker_video, bbox_shift=0)
video = musetalker.inference_noprepare(
    audio_path,
    sadtalker_video,
    bbox_shift=0,
    batch_size=4,
    fps=25
)
```

## 七、经验总结

### 7.1 成功经验

1. **组合方案效果最好**：SadTalker提供自然表情，MuseTalk提供精准口型
2. **文本清理很重要**：Markdown符号会影响TTS语音质量
3. **ngrok免费版需要特殊处理**：添加header绕过警告页面
4. **先测试再部署**：每个模块单独测试通过后再整合

### 7.2 踩坑教训

1. **不要只看一个方案**：MuseTalk口型好但表情假，需要组合使用
2. **参数名要确认**：不同版本的API参数名可能不同
3. **依赖版本要锁定**：AutoDL环境依赖冲突严重
4. **GPU显存要监控**：Windows系统本身占用大量显存

### 7.3 优化方向

1. **减少耗时**：540秒太长，可以考虑模型量化或异步处理
2. **提升口型**：调整MuseTalk的bbox_shift参数
3. **增加表情**：探索其他数字人模型（如Wav2Lip）
4. **流式输出**：实现边生成边播放
