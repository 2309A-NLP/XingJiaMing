# 性能优化方案

## 问题诊断

| 问题 | 影响 | 位置 |
|------|------|------|
| time.sleep()在异步上下文 | 阻塞事件循环，降低并发 | fastapi_app.py |
| 同步数据库操作 | 请求线程阻塞等待DB | mysql.py |
| ConnectionPool finally无条件rollback | 误回滚已提交事务 | mysql.py |
| 无结果缓存 | 重复查询相同问题 | 全局 |

## 优化方案

### 1. 消除异步上下文中的阻塞调用

**问题代码：**
```python
# 在async函数中直接使用
time.sleep(3)  # 阻塞整个事件循环！
```

**修复方案：**
```python
import asyncio

# 替换 time.sleep
await asyncio.sleep(3)

# 如果必须调用同步阻塞IO，使用线程池
import asyncio
result = await asyncio.to_thread(sync_blocking_function, arg1, arg2)
```

**排查所有异步函数中的同步阻塞调用：**
```bash
# 查找异步函数中的time.sleep

# 查找异步函数中的同步数据库调用
grep -n "get_conn\|execute\|commit" fastapi_app.py | head -30
```

### 2. 异步数据库操作

**方案A：使用 aiomysql（推荐）**

```python
# app/core/async_db.py
import aiomysql
import os

_pool: aiomysql.Pool = None

async def get_pool() -> aiomysql.Pool:
    global _pool
    if _pool is None:
        _pool = await aiomysql.create_pool(
            host=os.getenv("MYSQL_HOST", "127.0.0.1"),
            port=int(os.getenv("MYSQL_PORT", 3306)),
            user=os.getenv("MYSQL_USER", "root"),
            password=os.getenv("MYSQL_PASSWORD"),
            db=os.getenv("MYSQL_DB", "rag_db"),
            charset="utf8mb4",
            minsize=5,
            maxsize=30,
            autocommit=True,
        )
    return _pool

async def execute(sql: str, args=None) -> int:
    pool = await get_pool()
    async with pool.acquire() as conn:
        async with conn.cursor() as cur:
            await cur.execute(sql, args)
            await conn.commit()
            return cur.rowcount

async def fetchone(sql: str, args=None) -> dict | None:
    pool = await get_pool()
    async with pool.acquire() as conn:
        async with conn.cursor(aiomysql.DictCursor) as cur:
            await cur.execute(sql, args)
            return await cur.fetchone()

async def fetchall(sql: str, args=None) -> list[dict]:
    pool = await get_pool()
    async with pool.acquire() as conn:
        async with conn.cursor(aiomysql.DictCursor) as cur:
            await cur.execute(sql, args)
            return await cur.fetchall()
```

**方案B：渐进迁移 — 同步代码包装为异步**

如果短期内无法全面迁移，先用线程池包装：

```python
import asyncio
from functools import partial

async def db_fetchone_async(sql, args=None):
    loop = asyncio.get_event_loop()
    return await loop.run_in_executor(None, partial(db_fetchone, sql, args))
```

### 3. 修复ConnectionPool事务管理

**问题代码：**
```python
def get_user(user_id):
    conn = pool.get_conn()
    try:
        # 查询操作
        ...
    except Exception:
        conn.rollback()  # 查询失败也rollback（无意义）
    finally:
        conn.rollback()   # 无条件rollback（bug！）
        pool.release(conn)
```

**修复方案：**
```python
# 方案1：autocommit模式（适用于简单查询）
pool = Pool(..., autocommit=True)

# 方案2：正确的事务管理
def execute_in_transaction(sql, args=None):
    conn = pool.get_conn()
    try:
        with conn.cursor() as cur:
            cur.execute(sql, args)
            conn.commit()
            return cur.lastrowid
    except Exception:
        conn.rollback()
        raise
    finally:
        pool.release(conn)

def fetch_in_autocommit(sql, args=None):
    conn = pool.get_conn()
    try:
        with conn.cursor(pymysql.cursors.DictCursor) as cur:
            cur.execute(sql, args)
            return cur.fetchall()
    finally:
        pool.release(conn)
```

### 4. 对话历史TTL优化

**现状：** Redis TTL 300秒（5分钟），用户稍有中断对话就丢失上下文。

**优化方案：**
```python
# 分层TTL策略
DIALOGUE_TTL = {
    "active":   30 * 60,      # 活跃对话: 30分钟
    "idle":     24 * 3600,     # 空闲对话: 24小时
    "archive":  7 * 24 * 3600, # 归档对话: 7天
}

# 每次访问时刷新TTL（滑动过期）
async def get_dialogue_history(user_id: int, character_id: int):
    key = f"dialogue:{user_id}:{character_id}"
    data = await redis.get(key)
    if data:
        await redis.expire(key, DIALOGUE_TTL["active"])  # 滑动续期
    return data

# 对话结束时降级为idle
async def mark_dialogue_idle(user_id: int, character_id: int):
    key = f"dialogue:{user_id}:{character_id}"
    await redis.expire(key, DIALOGUE_TTL["idle"])
```

### 5. 查询结果缓存

```python
# app/core/cache.py
import hashlib
import json
from typing import Optional

class QueryCache:
    """对相似问题进行语义缓存（简化版：精确匹配缓存）"""

    CACHE_PREFIX = "rag_cache:"
    CACHE_TTL = 3600  # 1小时

    @staticmethod
    def _make_key(question: str, role: str) -> str:
        normalized = question.strip().lower()
        h = hashlib.md5(normalized.encode()).hexdigest()[:12]
        return f"{QueryCache.CACHE_PREFIX}{role}:{h}"

    @staticmethod
    async def get(question: str, role: str) -> Optional[str]:
        key = QueryCache._make_key(question, role)
        return await redis.get(key)

    @staticmethod
    async def set(question: str, role: str, answer: str):
        key = QueryCache._make_key(question, role)
        await redis.setex(key, QueryCache.CACHE_TTL, answer)

# 在RAG管线中使用
async def rag_pipeline(question: str, role: str) -> str:
    # 1. 检查缓存
    cached = await QueryCache.get(question, role)
    if cached:
        return cached

    # 2. 正常RAG流程
    contexts = await retrieve(question, role)
    answer = await generate(question, contexts, role)

    # 3. 写入缓存
    await QueryCache.set(question, role, answer)
    return answer
```
