## 修复方案

### 1. JWT Secret环境变量化

**现状：**
```python
SECRET_KEY = "dev-secret-change-in-production"  # 硬编码！
```

**修复：**
```python
# app/config.py
import os
import secrets

class Settings:
    JWT_SECRET: str
    JWT_ALGORITHM: str = "HS256"
    JWT_EXPIRE_MINUTES: int = 60 * 24  # 24小时
    REFRESH_TOKEN_EXPIRE_DAYS: int = 7

    def __init__(self):
        self.JWT_SECRET = os.getenv("JWT_SECRET")
        if not self.JWT_SECRET:
            if os.getenv("ENV") == "production":
                raise RuntimeError("JWT_SECRET environment variable is required in production")
            self.JWT_SECRET = secrets.token_urlsafe(32)
            print(f"[WARN] Generated temporary JWT_SECRET: {self.JWT_SECRET}")

settings = Settings()
```

**.env.example：**
```bash
# 生成方式: python -c "import secrets; print(secrets.token_urlsafe(48))"
JWT_SECRET=your-48-char-random-secret-here
```

### 2. CORS配置修复

**现状：**
```python
allow_origins=["http://120.26.32.90", "http://localhost:3000"]
```

**修复：**
```python
# app/config.py
class Settings:
    cors_origins: list[str]

    def __init__(self):
        raw = os.getenv("CORS_ORIGINS", "http://localhost:3000")
        self.cors_origins = [o.strip() for o in raw.split(",") if o.strip()]

# app/main.py
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE"],
    allow_headers=["Authorization", "Content-Type"],
)
```

**.env.example：**
```bash
CORS_ORIGINS=https://yourdomain.com,http://localhost:3000
```

### 3. SMS验证码完善

**现状：** 验证码生成后存Redis但未发送，注册时未校验。

**修复方案：**

```python
# app/services/sms_service.py
import os
import random
import httpx
from typing import Optional

class SMSService:
    def __init__(self):
        self.api_key = os.getenv("SMS_API_KEY")
        self.api_secret = os.getenv("SMS_API_SECRET")
        self.template_id = os.getenv("SMS_TEMPLATE_ID")
        self.enabled = bool(self.api_key)

    async def send_code(self, phone: str, code: str) -> bool:
        if not self.enabled:
            # 开发模式：打印到控制台
            print(f"[DEV] SMS code for {phone}: {code}")
            return True

        # 生产模式：调用短信API（阿里云/腾讯云示例）
        async with httpx.AsyncClient() as client:
            resp = await client.post(
                "https://dysmsapi.aliyuncs.com/",
                params={
                    "PhoneNumbers": phone,
                    "TemplateParam": f'{{"code":"{code}"}}',
                    "TemplateCode": self.template_id,
                    # ... 签名参数
                },
            )
            return resp.status_code == 200

sms_service = SMSService()
```

```python
# app/api/auth.py — 注册时校验验证码
@router.post("/register")
async def register(req: RegisterRequest):
    # 1. 校验验证码
    stored_code = await redis.get(f"sms_code:{req.phone}")
    if not stored_code or stored_code != req.code:
        raise HTTPException(400, "验证码错误或已过期")

    # 2. 创建用户
    ...

    # 3. 删除已使用的验证码
    await redis.delete(f"sms_code:{req.phone}")
```

**前端发送验证码接口：**
```python
@router.post("/send-code")
async def send_code(phone: str = Body(..., embed=True)):
    # 频率限制：同一手机号60秒内只能发一次
    if await redis.exists(f"sms_cooldown:{phone}"):
        raise HTTPException(429, "请60秒后重试")

    code = f"{random.randint(100000, 999999)}"
    await redis.setex(f"sms_code:{phone}", 300, code)       # 5分钟有效
    await redis.setex(f"sms_cooldown:{phone}", 60, "1")     # 60秒冷却

    await sms_service.send_code(phone, code)
    return {"msg": "验证码已发送"}
```

### 4. 数据库密码加固

**部署检查脚本：**
```bash
#!/bin/bash
# scripts/check_security.sh

echo "=== Security Check ==="

# 检查默认密码
if grep -q "123456" .env 2>/dev/null; then
    echo "[FAIL] MySQL using default password!"
fi

# 检查JWT secret
if grep -q "dev-secret" .env 2>/dev/null; then
    echo "[FAIL] JWT secret is default!"
fi

# 检查CORS
if grep -q "120.26.32.90" .env 2>/dev/null; then
    echo "[WARN] CORS using IP address instead of domain"
fi

echo "=== Check Complete ==="
```

### 5. HTTPS部署（Nginx反向代理）

```nginx
# /etc/nginx/sites-available/rag-api
server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    ssl_certificate     /etc/letsencrypt/live/api.yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.yourdomain.com/privkey.pem;

    # 安全头
    add_header Strict-Transport-Security "max-age=31536000" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "DENY" always;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE流式响应支持
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 300s;
    }
}

server {
    listen 80;
    server_name api.yourdomain.com;
    return 301 https://$host$request_uri;
}
```
