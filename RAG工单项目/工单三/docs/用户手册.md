# 用户手册 - RAG 智能问答系统（工单3）

## 快速开始

### 启动系统
1. 确保 Milvus 已启动（Docker 容器 `milvus-standalone`）
2. 双击 `start.bat`，自动启动后端和前端
3. 等待模型加载完成（约 30-60 秒）
4. 打开浏览器访问 http://localhost:5173

### 访问地址
| 服务 | 地址 |
|------|------|
| 前端页面 | http://localhost:5173 |
| 后端 API | http://localhost:8003 |
| API 文档 | http://localhost:8003/docs |
| 健康检查 | http://localhost:8003/api/health |

## 功能说明

### 问答
在输入框输入问题，系统会从已加载的文档中检索相关信息并生成回答。

**支持的问题类型**：
- 事实性问题："公司的注册资本是多少？"
- 列举性问题："募集资金拟投资哪些项目？"
- 比较性问题："文档一和文档二的区别在哪儿？"
- 简单问题："公司老板是谁"

**特殊功能**：
- 问候语直接回复（不检索文档）
- 回答中标注信息来源文档
- 支持中英文双语

### 文档管理
- 点击上传按钮上传 PDF 文件
- 系统自动解析 PDF（MinerU + OCR）
- 解析完成后自动建立索引
- 支持多份文档共存

### 对话管理
- 左侧栏显示历史对话列表
- 支持创建、切换、删除对话
- 对话记录保存在 SQLite 数据库

## 常见问题

### Q: 启动报端口占用怎么办？
A: `start.bat` 会自动清理占用端口的进程。如果仍然失败，手动执行：
```bash
taskkill /F /IM python.exe
```

### Q: 回答不准确怎么办？
A: 可能原因：
1. 文档未正确解析 — 检查 `data/` 目录下是否有 `_refined.md` 文件
2. 问题太模糊 — 尝试更具体的问题
3. 信息不在文档中 — 系统会坦诚告知"未找到"

### Q: 响应时间太长怎么办？
A: 响应时间主要取决于 DeepSeek API 负载：
- 问候语：< 0.1 秒
- 简单查询：2-3 秒
- 复杂查询：3-6 秒

如果持续很慢，检查网络连接或 DeepSeek API 状态。

### Q: 如何添加新文档？
A: 在前端页面点击上传按钮，选择 PDF 文件即可。新文档会追加到现有索引中，不会清除旧数据。

### Q: 如何重新构建索引？
A: 删除 `storage/chunks_cache.pkl` 和 Milvus 中的数据，重启服务即可重新构建。
