# 更新日志 - 工单6

## v3.0.0 - 2026-06-04

### 新增功能

**检索策略配置界面**
- 前端设置弹框（左下角三点按钮），支持实时切换检索策略
- 检索模式：向量检索 / 全文检索 / 混合检索
- 匹配模式：标准 / 布尔查询 / 短语匹配 / 模糊匹配 / 自动检测
- 重排算法：BGE / LLM / TF-IDF / 自适应
- 嵌入模型：BGE-M3 / M3E 等多模型切换
- 权重调整：向量权重和全文权重滑块
- Top-K 返回数量滑块
- 配置持久化到 localStorage，刷新不丢失

**布尔查询**
- 支持 AND/OR/NOT 组合条件
- 示例：`人工智能 AND 机器学习`、`深度学习 OR 神经网络`、`人工智能 NOT 机器人`
- 自动检测查询类型，无需手动切换

**短语匹配**
- 引号内内容必须完整出现
- 示例：`"招股说明书"`、`"注册资本"`
- 先 BM25 初筛，再精确短语匹配过滤

**模糊匹配**
- 基于编辑距离的相似词匹配
- 容忍拼写错误，适合近义词场景
- 对长度 ≥3 的词做模糊匹配

**多种嵌入模型支持**
- 支持 BGE-M3、M3E 等多种嵌入模型
- 模型列表从 `.env` 的 `EMBEDDING_MODELS` 配置读取
- 已加载的模型自动缓存，避免重复加载
- 新增 `/api/embedding/models` 和 `/api/embedding/switch` API

**多种重排算法**
- BGE：基于深度学习（bge-reranker-base），准确率高，需要 GPU
- LLM：基于大语言模型（DeepSeek API），最准确但最慢
- TF-IDF：基于 sklearn TF-IDF 相似度，速度最快
- 自适应：根据查询长度自动选择最合适的算法
- 新增 `create_reranker()` 工厂函数

**检索质量评估**
- 新增独立评估弹框（侧边栏 📊 按钮）
- 评估指标：准确率（目标 ≥90%）、召回率（目标 ≥95%）、响应时间（目标 <3s）
- 总评卡片：优秀 / 良好 / 需优化
- 三项核心指标带进度条
- 达标率横条图
- 分类得分：业务、风险、财务、结构、人力
- 逐题详情：可折叠，显示关键词命中数
- 内置 8 个标准测试问题，支持自定义测试问题集

**配置标签**
- 回答下方显示实际使用的检索配置
- 绿色标签：模式、匹配、重排、模型
- 标准匹配不显示（默认值），非标准匹配才显示

# 更新日志 - 工单5

## v2.1.0 - 2026-06-04

### 新增功能
- **多轮对话**：基于 Redis 短期记忆，支持上下文追问
  - 查询时自动读取最近 10 轮对话历史，注入 LLM 上下文
  - 支持追问场景（如"那第二家呢？"、"它的注册资本呢？"）
  - 支持个人信息记忆（如"我叫李达" -> "我是谁？" -> "你是李达"）
  - 对话历史 TTL 1 小时，自动过期
- **QueryRequest 支持 chat_id**：前端请求带上对话 ID，后端据此读写 Redis
- **LLM Generator 支持 history 参数**：`generate()` 和 `generate_stream()` 均支持传入历史消息

### 技术变更
- 新增 `scripts/memory/session_memory.py`：Redis 短期记忆
- 修改 `api/models.py`：QueryRequest 新增 `chat_id` 字段
- 修改 `scripts/pipeline/llm_generator.py`：支持历史消息注入
- 修改 `api/routes/query.py`：读取 Redis 历史并存储本轮对话
- 修改 `frontend/src/api.ts`：`queryStream` 新增 `chatId` 参数
- 修改 `frontend/src/App.tsx`：`handleSend` 传入 `activeId` 作为 `chatId`

### 修复
- 修复 `chat.py` 与 `query.py` 重复存储 Redis 导致消息重复的问题
