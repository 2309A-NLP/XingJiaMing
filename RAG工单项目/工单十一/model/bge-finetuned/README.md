# SentenceTransformer

This is a [sentence-transformers](https://www.SBERT.net) model trained. It maps sentences & paragraphs to a 768-dimensional dense vector space and can be used for retrieval.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
<!-- - **Base model:** [Unknown](https://huggingface.co/unknown) -->
- **Maximum Sequence Length:** 128 tokens
- **Output Dimensionality:** 768 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

<!-- - **Language:** Unknown -->
<!-- - **License:** Unknown -->

### Model Sources

- **Documentation:** [Sentence Transformers Documentation](https://sbert.net)
- **Repository:** [Sentence Transformers on GitHub](https://github.com/huggingface/sentence-transformers)
- **Hugging Face:** [Sentence Transformers on Hugging Face](https://huggingface.co/models?library=sentence-transformers)

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'BertModel'})
  (1): Pooling({'embedding_dimension': 768, 'pooling_mode': 'cls', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    '为啥银行现在这么重视风险防控？',
    '贵问题对实体经济发展的制约作用，促进实体经济持续转型和升级；\n二是持续强化金融风险防控仍是当务之急。商业银行将会在严监管的态势下，继续严格遵守监管的各项要求，不断提升自身的风险管理水平，持续提高银行资产的质量，为促进金融稳定与金融安全夯实基础；\n三是继续坚持科技引领与赋能金融仍是必然趋势。',
    '产生重大影响。\n于2019年度及2018年度，本集团没有属于非持续的以公允价值计量的资产或负债项目。\n7.1估值技术、输入参数和流程\n金融资产和金融负债的公允价值是根据以下方式确定：\n-拥有标准条款和条件并在活跃流通市场上交易的金融资产和金融负债的公允价值是参考市场标价确定。\n-对于非期权类的衍生金融工具，其公允价值利用工具期限内适用的收益率曲线按折现现金流分析来确定。\n-其他金融资产和金融负债的公允价值是根据公认定价模型或采用对类似工具可观察的当前市场标价根据折现现金流分析而确定。',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 768]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 0.5694, 0.0340],
#         [0.5694, 1.0000, 0.1455],
#         [0.0340, 0.1455, 1.0000]])
```
