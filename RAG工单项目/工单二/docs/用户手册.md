# 用户手册 - RAG 智能问答系统（工单2）

## 一、系统简介

基于大语言模型的智能问答系统，支持对 PDF 文档进行内容检索和问答。
支持中英文双向翻译，专业问题首 token 响应约 3 秒，问候语约 1 秒。

## 二、启动系统

### 方式一：一键启动
1. 双击项目根目录下的 `start.bat`
2. 系统自动检测并清理被占用的端口
3. 浏览器访问 http://localhost:5173

### 方式二：手动启动
```bash
# 后端（使用项目 .venv）
.venv\Scripts\python.exe run.py

# 前端
cd frontend && npm run dev
```

### 首次启动
- 首次启动需加载 AI 模型（约 1 分钟）
- 页面顶部显示"后端正在初始化"提示
- 加载完成后输入框自动启用

## 三、上传 PDF 文档

1. 点击输入框左侧的 📎 上传按钮
2. 选择 PDF 文件
3. 系统自动解析（支持 MinerU + PaddleOCR）
4. 解析完成即可提问

## 四、提问

### 基本提问
1. 在输入框输入问题
2. 按回车或点击发送
3. 等待 AI 回答（专业问题约 3 秒，问候语约 1 秒）

### 回答内容
- **回答文字**：基于文档内容生成
- **响应时间**：本次处理耗时
- **来源引用**：回答依据的文档片段
- **Query 分析**：意图识别、关键词提取

### 翻译功能
- 每个消息气泡右下角有"翻译"按钮
- 中文消息点击后显示英文翻译
- 英文消息点击后显示中文翻译
- 再次点击收起翻译

### 对比功能
- AI 回复下方点击"对比"按钮
- 左右对比 RAG 回答 vs 纯 LLM 回答
- 查看检索增强的效果差异

## 五、历史对话

- 左侧边栏显示历史对话列表
- 点击切换查看
- 支持删除对话

## 六、常见问题

### Q: 页面显示"后端未响应"
A: 后端未启动。运行 `.venv\Scripts\python.exe run.py` 或双击 `start.bat`。

### Q: 页面显示"后端正在初始化"
A: 正在加载模型，等待约 1 分钟。

### Q: 提问后一直加载
A: 可能原因：
- 首次请求触发模型初始化
- 网络不稳定
- 刷新页面重试

### Q: 回答不准确
A: 可能原因：
- 文档中没有相关内容
- 换个问法或更具体的问题
- 使用"对比"功能查看差异

### Q: 翻译按钮没有反应
A: 刷新页面（Ctrl+Shift+R），确保后端正常运行。

### Q: 如何切换语言？
A: 不需要手动切换。直接输入中文或英文，系统自动识别并用对应语言回答。点击翻译按钮可查看另一种语言的翻译。

### Q: 重复提问会不会更快？
A: 会。系统有查询缓存，5 分钟内相同问题直接返回缓存结果，响应约 0.01 秒。
