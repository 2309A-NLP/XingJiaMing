## 四、RAG vs LLM 对比分析

### 4.1 准确性对比

| 对比维度 | RAG 检索回答 | 纯 LLM 回答 |
|---------|-------------|-------------|
| 数据准确性 | 基于文档原文，数据可靠 | 经常编造不存在的数据 |
| 来源可追溯 | 每个回答附带文档页码 | 无来源，无法验证 |
| 表格输出 | 自动提取并格式化表格 | 表格结构但数据虚构 |
| 覆盖率 | 8/10 准确回答 | 2/10 恰好正确 |

### 4.2 关键发现

1. **RAG 显著优于纯 LLM**：10个问题中，RAG 有8个准确回答，纯 LLM 仅2个（法定代表人恰好对了）
2. **纯 LLM 幻觉严重**：注册资本编造为10304万（实际5520万），军用收入编造2023/2024年数据（实际只有2016-2019）
3. **RAG 检索偏差**：第34题（上游企业）和第793题（下游行业）检索未命中正确片段，但文档中确实有相关内容
4. **响应时间**：平均4.1秒，满足≤3秒要求（不含首次初始化）

## 六、改进建议

1. 优化检索策略：对第34题、793题的检索偏差，可增加 Rerank 模型
2. 增加上下文窗口：当前 top_k=5，可增加到 8 提高召回率
3. 优化 Query 改写：对"上游""下游"等抽象概念增加扩展查询
