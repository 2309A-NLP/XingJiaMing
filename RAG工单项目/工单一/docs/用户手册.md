# 用户手册 - RAG 智能问答系统

## 一、系统简介

本系统是一个基于大语言模型的智能问答系统，能够针对 PDF 文档（如招股说明书）进行内容检索和问答。系统支持中文和英文问答，响应时间一般在 3-5 秒内。

## 二、启动系统

### 方式一：一键启动
1. 双击项目根目录下的 `start.bat`
2. 等待终端窗口出现，系统会自动启动后端和前端
3. 浏览器访问 http://localhost:5173

### 方式二：手动启动
1. 启动后端：在项目根目录运行 `python run.py`
2. 启动前端：在 `frontend` 目录运行 `npm run dev`
3. 浏览器访问 http://localhost:5173

### 首次启动说明
- 首次启动时，系统需要加载 AI 模型（约 1 分钟）
- 页面顶部会显示蓝色提示"后端正在初始化，加载模型中，请稍候..."
- 加载完成后，输入框自动启用，即可开始提问

## 三、上传 PDF 文档

1. 点击输入框左侧的 📎 上传按钮
2. 在弹出的文件选择框中选择 PDF 文件
3. 系统会自动解析文档，提取文字和表格内容
4. 解析完成后会提示"文档解析完成！共 X 页，Y 个文本块"
5. 解析完成后即可针对文档内容提问

### 注意事项
- 仅支持 PDF 格式文件
- 解析时间取决于文档页数，一般 1-3 分钟
- 解析后的内容会自动保存，下次启动无需重新解析

## 四、提问

### 输入问题
1. 在底部输入框中输入您的问题
2. 按回车键或点击发送按钮提交问题
3. 系统会自动分析问题并返回回答

### 回答内容
AI 回复包含以下信息：
- **回答文字**：基于文档内容生成的准确回答
- **响应时间**：本次问答的处理耗时
- **问题分析**（点击展开）：
  - 意图类型：事实性/列举性/总结性等
  - 消歧后的问题：系统优化后的查询
  - 关键词：提取的核心词汇
- **来源引用**（点击展开）：回答所依据的文档片段及页码
- **RAG vs LLM 对比**（点击弹窗）：对比 RAG 检索回答和纯 LLM 回答的差异

### 示例问题
- 公司注册资本是多少？
- 报告期内来自军用领域的收入分别是多少？
- 公司参与制定了哪个技术标准？
- 电子信息行业的上游涉及哪些企业？

## 五、查看历史对话

1. 左侧边栏显示所有历史对话列表
2. 点击任意对话可切换查看
3. 对话按时间倒序排列，最新的在最上面
4. 点击对话右侧的删除按钮可删除对话

## 六、新建对话

- 点击侧边栏顶部的"新对话"按钮
- 系统会创建一个新的空白对话

## 七、RAG vs LLM 对比功能

1. 在 AI 回复下方点击"RAG vs LLM 对比"按钮
2. 弹出对比窗口，左右两栏展示：
   - **左侧**：RAG 检索回答（基于文档）
   - **右侧**：纯 LLM 回答（不参考文档）
3. 底部显示响应时间和来源数量
4. 点击右上角 ✕ 或底部"关闭"按钮退出

## 八、常见问题

### Q: 页面显示"后端未响应或已断开"
A: 后端服务未启动。请确认已运行 `python run.py` 或双击 `start.bat`。

### Q: 页面显示"后端正在初始化"
A: 系统正在加载 AI 模型，请等待约 1 分钟。加载完成后输入框会自动启用。

### Q: 提问后一直显示加载中
A: 可能原因：
- 首次请求触发模型初始化，需等待约 1 分钟
- 网络连接不稳定，DeepSeek API 响应慢
- 刷新页面重试

### Q: 回答不准确或找不到答案
A: 可能原因：
- 文档中确实没有相关内容
- 尝试换个问法或更具体的问题
- 使用"RAG vs LLM 对比"查看差异

### Q: 如何更新文档内容？
A: 上传新的 PDF 文件即可，系统会自动重新解析和索引。
