# 技术文档 - RAG 智能问答系统（工单1）

工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 一、系统架构

```
┌─────────────────────────────────────────────────┐
│                   前端 (React + Vite)            │
│  ChatArea ─ InputBox ─ Sidebar                   │
└──────────────────┬──────────────────────────────┘
                   │ HTTP / SSE
┌──────────────────▼──────────────────────────────┐
│               后端 (FastAPI)                     │
│  ┌─────────────┐  ┌──────────────┐              │
│  │ Query 理解   │  │  文档解析     │              │
│  │ (DeepSeek)   │  │  (PDF→MD)    │              │
│  └──────┬──────┘  └──────┬───────┘              │
│         │                │                       │
│  ┌──────▼──────┐  ┌──────▼───────┐              │
│  │  双路检索    │  │  分块+向量化  │              │
│  │ BM25+Milvus │  │  (BGE-M3)    │              │
│  └──────┬──────┘  └──────────────┘              │
│         │                                        │
│  ┌──────▼──────┐                                │
│  │ LLM 生成    │                                │
│  │(DeepSeek)   │                                │
│  └─────────────┘                                │
└─────────────────────────────────────────────────┘
         │              │
    ┌────▼────┐   ┌─────▼─────┐
    │ Milvus  │   │ SQLite    │
    │(向量库) │   │(对话记录) │
    └─────────┘   └───────────┘
```

## 二、技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript | 组件化开发 |
| 构建工具 | Vite | 快速热更新 |
| 后端框架 | FastAPI | 异步高性能 |
| LLM | DeepSeek-Chat | 国产大模型，API 调用 |
| Embedding | BGE-M3 | 本地部署，1024维向量 |
| 向量数据库 | Milvus (Docker) | 高效向量检索 |
| 稀疏检索 | BM25 (rank_bm25) | 关键词匹配补充 |
| 对话存储 | SQLite | 轻量持久化 |
| 文档解析 | PyMuPDF + Marker | PDF 文字/表格提取 |

## 四、API 接口

| 接口 | 方法 | 说明 |

| `/api/chats/{id}/messages` | GET/POST | 消息列表/保存 |

## 五、核心流程

### 5.1 问答流程

```
用户输入问题
    │
    ▼
_is_greeting() 判断 ──→ 问候语 → 直接调 LLM → 返回
    │
    ▼ (文档相关)
Query 理解 (DeepSeek)
  - 意图识别
  - 消歧
  - 分解子问题
  - 提取关键词
    │
    ▼
双路检索
  - 向量检索 (Milvus + BGE-M3)
  - BM25 关键词匹配
  - 合并去重 + 排序
    │
    ▼
LLM 生成回答 (DeepSeek)
  - 注入检索上下文
  - 流式输出
    │
    ▼
返回：答案 + 来源 + Query 分析
```

### 5.2 文档解析流程

```
上传 PDF
    │
    ▼
BatchProcessor
  - PDF → 图片/文字提取
  - 多引擎解析 (OCR/文本)
  - 清洗 (cleaner.py)
    │
    ▼
Chunker 分块
  - 按章节/段落切分
  - 支持 overlap 重叠
  - 生成父子块关系
    │
    ▼
Embedder 向量化
  - BGE-M3 编码
  - 1024 维向量
    │
    ▼
存储
  - Milvus (向量)
  - BM25 (关键词索引)
```
