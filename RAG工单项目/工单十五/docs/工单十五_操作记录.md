## 1. 响应时间优化

### 1.1 问题分析

**原始问题：**
- 响应时间：~13秒
- 答案长度：~1000字
- 用户要求：≤3秒

**瓶颈分析：**
- 首字时间：~4秒（MiMo API网络延迟+模型推理）
- 生成时间：~7-10秒（生成1000字）
- 结论：瓶颈在MiMo API，非检索

### 1.2 优化措施

#### 1.2.1 Prompt优化

**修改位置：** RAGFlow数据库 `dialog` 表

**原始Prompt：**
```
You are an intelligent assistant. Please summarize the content of the dataset to answer the question. Please list the data in the dataset and answer in detail. When all dataset content is irrelevant to the question, your answer must include the sentence "The answer you are looking for is not found in the dataset!" Answers need to consider chat history.
```

**优化后Prompt：**
```
You are an intelligent assistant. Please answer the question based on the knowledge base below. IMPORTANT: 1) Answer concisely in 1-3 sentences. 2) Only state facts directly supported by the knowledge base. 3) If the answer is not found, say "The answer you are looking for is not found in the dataset!"
```

**执行命令：**
```sql
UPDATE dialog SET prompt_config = '{"system": "You are an intelligent assistant. Please answer the question based on the knowledge base below. IMPORTANT: 1) Answer concisely in 1-3 sentences. 2) Only state facts directly supported by the knowledge base. 3) If the answer is not found, say \\"The answer you are looking for is not found in the dataset!\\" \\n      Here is the knowledge base:\\n      {knowledge}\\n      The above is the knowledge base.", "prologue": "Hi! I\'m your assistant. What can I do for you?", "parameters": [{"key": "knowledge", "optional": false}], "empty_response": "Sorry! No relevant content was found in the knowledge base!", "quote": true, "tts": false, "refine_multiturn": true}' WHERE id='5c1d5dd867e111f18ccf67d6b18d4879';
```

#### 1.2.2 LLM参数优化

**修改位置：** RAGFlow数据库 `dialog` 表

**优化参数：**
- `max_tokens`: 500（限制输出长度）
- `temperature`: 0.1（提高确定性）
- `top_k`: 15（减少检索量）

**执行命令：**

### 1.3 优化效果

### 4.2 多路召回融合

**文件：** `/ragflow/rag/nlp/search.py`

**修改内容：**
1. 导入`detect_visual_reference`函数
2. 在`retrieval()`方法中检测视觉引用
3. 如果检测到视觉引用，使用增强查询进行额外检索
4. 将图片描述chunk添加到结果开头（优先级最高）

**核心代码：**
```python
from rag.nlp.query import detect_visual_reference

async def retrieval(self, question, ...):
    # 检测视觉引用
    visual_ref = detect_visual_reference(question)
    
    # 如果检测到视觉引用，使用增强查询进行额外检索
    if visual_ref["has_visual_ref"] and visual_ref["enhanced_query"]:
        enhanced_req = {
            "question": visual_ref["enhanced_query"],
            "topk": 50,
            "similarity": 0.1,
        }
        enhanced_sres = await self.search(enhanced_req, ...)
        
        # 提取图片描述chunk
        for chunk_id in enhanced_sres.ids:
            chunk = enhanced_sres.field.get(chunk_id, {})
            if "图" in content and "描述" in content:
                enhanced_chunks.append(chunk)
    
    # 合并增强的图片描述chunks
    if enhanced_chunks:
        ranks["chunks"].insert(0, enhanced_chunk)
```

### 4.3 Prompt优化

**文件：** `/ragflow/rag/prompts/generator.py`

**修改内容：**
1. 修改`kb_prompt()`函数
2. 检测图片描述chunk（`is_image_desc`标记）
3. 图片描述chunk优先展示
4. 添加图片描述提示语

**核心代码：**
```python
def kb_prompt(kbinfos, max_tokens, hash_id=False):
    # 检测图片描述chunk
    has_image_desc = False
    image_desc_chunks = []
    text_chunks = []
    
    for i, ck in enumerate(kbinfos["chunks"][:chunks_num]):
        if ck.get("is_image_desc", False):
            has_image_desc = True
            image_desc_chunks.append((i, ck))
        else:
            text_chunks.append((i, ck))
    
    # 如果有图片描述chunk，添加特殊提示
    if has_image_desc:
        image_desc_hint = (
            "\n\n【重要提示】以下知识库内容包含技术图纸/图表的详细描述。"
            "当问题涉及图表、图示、部件位置、部件关系等视觉信息时，"
            "请优先参考图片描述部分的内容进行回答。"
        )
    
    # 先添加图片描述chunk（优先级更高）
    for i, ck in image_desc_chunks:
        cnt += " [图片描述]"  # 标记为图片描述
        knowledges.append(cnt)
    
    return knowledges, image_desc_hint
```

**本地备份：** `/home/swcqybz/ragflow_patch/generator.py`
